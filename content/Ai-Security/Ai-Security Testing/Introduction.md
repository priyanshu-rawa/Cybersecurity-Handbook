# AI Security Testing — Introduction

## The gap this fills

You can know *what* vulnerabilities exist. That's different from knowing *how to find them* in your specific system before attackers do.

That's what AI security testing is for — specifically, AI red teaming. Probing your AI systems with adversarial techniques to find weaknesses first.

It's required in any responsible AI development lifecycle, and it works differently from traditional pen testing in ways that matter for how you plan and run it.
