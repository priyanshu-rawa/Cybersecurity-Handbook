# Contributing to Cybersecurity Handbook

Thank you for considering contributing! This handbook is built by the community, for the community.

## How to Contribute

1. **Add a new note** – Fork the repo, add your note in the appropriate folder, and submit a Pull Request (PR).
2. **Fix errors** – If you spot a mistake, open an issue or submit a PR with the correction.
3. **Improve clarity** – Reword or expand existing notes to make them easier to understand.
4. **Add examples** – Include practical commands, diagrams, or real-world scenarios.

## Guidelines

- Keep notes **concise and practical** – focus on real-world scenarios.
- Include **examples, commands, or diagrams** where helpful.
- Use **Markdown** formatting – headers, code blocks, lists.
- Place your note in the **correct category** (e.g., `cryptography/`, `web-security/`).
- If you're unsure, open an issue first – we can discuss the best location.
- Write in **clear, accessible English** – avoid jargon where possible.

## How to Submit

1. Fork the repository.
2. Create a new branch: `git checkout -b add-note-xyz`.
3. Add your changes.
4. Commit and push to your fork.
5. Open a Pull Request against the `main` branch.

## What We're Looking For

- **New topics** – Missing a subject? Add it!
- **Corrections** – Found an error? Fix it.
- **Improvements** – Think something can be explained better? Reword it.
- **Labs** – Practical exercises and walkthroughs.
- **Diagrams** – Visual explanations of complex concepts.

## Need Help?

Open an issue – we'll guide you.

**Thank you for helping make this a world‑class resource!**
